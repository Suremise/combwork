# Work on a card: after the review

**Passed and Done aren't yours to move.** A passing verdict moves the card on, and how it finishes is the project's: the reply, then `cw_read_task`, says what's next. Where Combwork merges, the card's `merge` follows it through the queue: wait for Done or a return. Where you merge, use merge-ready, then `cw_report_merge` with the merge commit (Combwork checks it is in). Where merges aren't checked, `cw_report_merge` says it's finished, with no merge to prove. Where the user's OK comes first, it waits for them. Where the user integrates (jj), it waits for them: there's nothing for you to merge. Where the work is done once committed, accepted (no version control) or reviewed, and for a no-code card, it finishes on its own.

**Back for more work:** A card of yours already in Doing (a failed review sends it back there) needs no start: carry on. One back from Passed or Done for more work: `cw_update_task` with `column: "doing"`. A card On Hold is parked: work on it only when the user asks.
