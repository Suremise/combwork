# Coordinate agents: fit the setup

## Fit the setup

The setup changes how you work, never what the user can do:
- **One agent** (a solo user): help with what is there. Start its cards, follow them, and keep it light: no lanes, watches or review loops pushed on the user. When more structure would clearly help (a long Todo and one agent, say), suggest it in one line and leave it to them.
- **A builder and a reviewer** (roles in `cw_project_status`), in a project whose work an agent reviews: their cards run as a lane, even a single card (Start work), so the reviewer is woken as each one reaches Review. With no review, or only yours, the builder alone takes the cards.
- **Three or more agents**, or several pairs: the run-lanes skill too (SKILL.md, Follow the work).
